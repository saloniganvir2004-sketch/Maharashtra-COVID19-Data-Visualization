# Maharashtra COVID-19 Data Visualization

## Project Overview

This project demonstrates Exploratory Data Analysis and Data Visualization using Maharashtra's district-wise COVID-19 statistics.

It uses Python libraries to visualize active cases, deceased cases, recovery rates, and fatality statistics through different graphical representations.

## Dataset

Maharashtra Latest COVID Cases dataset.

### Features Used

- Districts
- Deceased
- Active Cases
- Fatality Rate (%)
- Recovery Rate (%)

## Implemented Visualizations

### 1. Line Graph
Visualizes the relationship between deceased cases and active cases.

### 2. Bar Graph
Displays deceased cases across different districts.

### 3. Scatter Plot
Examines the relationship between deceased and active cases.

### 4. Pie Chart
Represents active case values.

### 5. Histogram
Displays the distribution of active COVID-19 cases.

### 6. Boxplot
Visualizes the distribution of deceased cases.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab / Jupyter Notebook

1. Open the notebook in Google Colab or Jupyter Notebook.
